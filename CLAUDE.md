# CLAUDE.md

## Project

TrickFire Robotics internal dashboard — Next.js 15 app router, SQLite + Drizzle ORM, better-auth, Tailwind CSS v4 + shadcn/ui.

## Package Manager

Use `pnpm`. Never `npm` or `yarn`.

## After Every Change

Run these before considering a task done:

```bash
pnpm check      # lint + format check + typecheck
pnpm test       # vitest
```

Fix all errors and warnings before finishing.

## Commits

This project uses [Conventional Commits](https://www.conventionalcommits.org/) enforced by commitlint + Husky.

Format: `<type>: <description>`
Types: `feat`, `fix`, `refactor`, `chore`, `docs`, `style`, `perf`, `ci`, `revert`

Examples:

- `feat: add order export button`
- `fix: minecraft whitelist not persisting`
- `refactor: split auth helpers into separate module`

Husky runs `commitlint` on every commit message — malformed messages are rejected.

**IMPORTANT**: Commit under my name only, never co-author commits.

## Documentation

- Update `docs/`, `README.md` & `CONTRIBUTING.md` when making a major change to architecture, integrations, or deployment.
- Do not document routine changes or internal implementation details.
- Do not add inline comments unless the _why_ is very non-obvious to a future reader.

## Database

- Edit schema in `src/lib/db/schema.ts`.
- After schema changes: `pnpm db:generate` then `pnpm db:migrate`.
- Never edit files in `drizzle/migrations/` by hand.
- `src/lib/db/auth-schema.ts` is auto-generated by better-auth — don't touch it. Run `pnpm auth:generate` if auth config changes.

## Deployment

The production server is accessible via Tailscale as `tfserver` (requires Tailscale to be set up). CI deploys automatically on push to `main` using the self-hosted GitHub Actions runner on `tfserver`.

Manual deploy: `pnpm deploy` (runs `scripts/deploy.sh`).

## Environment

Copy `.env.example` to `.env.local` for local development. Production uses `.env.production` on the server.

Key variables: `BETTER_AUTH_SECRET`, `DATABASE_PATH`, `RESEND_API_KEY`, `TAILSCALE_API_KEY`, `GITHUB_TOKEN`, `NEXT_PUBLIC_SENTRY_DSN`.
